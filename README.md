# Інна Михайлова — версия для согласования

Светлый дизайн с бордовым заголовком «4 кроки», выбранный клиенткой. Сохранены тексты правок, цена 499 вместо 2999 грн, программа четырёх дней, бонусы и шесть отзывов. В блоке об авторе установлено последнее присланное фото.

Статический HTML/CSS/JS. Публикация через GitHub Pages из корня ветки `codex/preview`.

Предпросмотр: https://pobedazanami.github.io/inna-blog-editorial/

Кнопки оплаты пока не подключены к платёжной системе; это версия для согласования дизайна и текстов.
